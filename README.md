# TIPE Fourier / Bézier
*Started Mar 2022 — TIPE, CPGE (prépa)*

Python programs I wrote for my TIPE in prépa, on compact encoding of line drawings (letters, sketches).

- [`projet Encodage fourier/`](projet%20Encodage%20fourier) — encoding line-based shapes as Fourier series, keeping only the coefficients to save memory
- [`bezier/`](bezier) — drawing and saving shapes as Bézier curves (De Casteljau)

Conclusion: Bézier curves beat Fourier for this task, but the Fourier approach was fun to explore.

# Encoding Drawings with Fourier Coefficients

Can thin-line shapes (letters, line drawings) be approximated well by a Fourier series, so you only store the coefficients? I tried it and checked how much memory that saves.

Short answer: not really practical — Bézier curves are much better for storing shapes. Still fun to play with.

See this video for more: https://www.youtube.com/watch?v=r6sGWTCMz2k

Code: `mathsvfinale.py`. Run it to recompute the coefficients and plots.
